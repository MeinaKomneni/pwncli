# 2026-06-17: 新增 gdb_cmd() — 运行时向 gdb 发送命令并获取输出

## 动机

打 heap 题时,gdb_script 只能设置程序启动时的初始化命令,无法在 exp 运行到中途时动态查看堆布局。需要一个函数,在 exp 脚本的任意位置向已经在跑的 gdb 窗口发送命令并拿回输出(如 `heap`、`x/40gx`、`bins`),使 AI 也能根据 gdb 输出来 debug。

## 方案

利用 tmux 的 `send-keys` + `capture-pane` 实现。gdb 跑在 tmux 分屏的右侧 pane 里,通过 `_get_tmux_info()` 定位 pane id。

## API

```python
output = gdb_cmd("heap")               # 发送命令,等待并返回输出
output = gdb_cmd("x/40gx 0x555...", wait=0.5)  # 复杂命令多等一会
```

## 改动文件

- `pwncli/utils/cli_misc.py`: 新增 `gdb_cmd()` 函数,加入 `__all__`
- `doc/cli_misc.md`: GDB 操作节补充 `gdb_cmd` 文档

## 实现要点

- 先轮询 `capture-pane` 等 gdb prompt 出现(确认 gdb 空闲)
- `send-keys C-l` 清屏,令 pane 只剩 prompt
- `send-keys '{cmd}' Enter` 发送命令
- 再次轮询等 prompt 重新出现(命令执行完毕)
- `capture-pane -p` 抓取当前可见内容,去掉首行命令回显和末尾 prompt
- `_get_tmux_info()` 定位 gdb pane(session:window.1)
- 仅 tmux 模式可用,非 tmux 时 warn 并返回空
- `timeout` 参数防止 gdb 卡死时无限等待
